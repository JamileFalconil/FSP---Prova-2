# FSP---Prova-2
O repositório está dividido em pastas, as quais possuem os arquivos necessários para a entrega completa de todos os requisitos do trabalho.
A pasta Scopus: dados possui os dados dos artigos exportados para usar no RStudio, para que fosse feita a revisão bibliométrica.
A pasta Base de dados possui a atualização dos dados base do trabalho anterior, contendo a explicação sobre a atualização e links de acesso aos dados, gráficos e imagens do PIB e IDEB.
A pasta biblioshiny possui os dados importados do Bibliometrix para a revisão bibliométrica.
A pasta ARTIGO FINALIZADO possui o artigo sobre a Inglaterra, Duque de Caxias e Nova Iguaçu.
